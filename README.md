# README #

La web de Pernas

### ¿Esto para qué es? ###

* Pues la web de Pernas. Tiene administración, gestor de páginas, blog, contacto y galerías.
* 0.9.5

### ¿Cómo lo instalo? ###

* Lo clonas, montas la base de datos, cambias los datos en los archivos de configuración que van en la raíz y a correr.
* Activar deflate_module y filter_module en Apache
* Poner los archivos de config y config_front en la carpeta superior al proyecto y configurar sus datos.

### No me ayuda ni el tato pero uso: ###

* Gentelella admin template
* Lydia-photography-magazine-site-template
* Swftmailer
* TinyMCE
* Nestable
* Dropzone
* gdpr-cookie-2.3

### ¿qué queda por hacer? ###

* Cambiar el apartado de 'Sobre mí' de la página principal.
* Addon del Instagram // cambiar por LightWidget.
* Ponerles metas a las galerías.
* Página 404
* Comprobar mailer
* Instalar Disqus
